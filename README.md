# big-edit
A save file editor for the PC/Steam version of Big Walk

**Please always back up your save file first!**

While the source code for this was mostly produced with AI assistance (thanks Gemini!), lots of manual effort was required to determine how the save files work and what the various obfuscated IDs and key values mean.

I won't be able to determine new IDs until I've completed things in my own save file, so updates may be slow! If you have a completed save file and would like to share, please let me know :)

Note: House House states that there is not canon terminology for the various things in the game. The save files use "gourd" for the primary collectables, so that's what is used here. Other items are labeled as makes sense to me.

## Features

- Open/close the large gates
- Unlock/disable features requiring completed big keys
- Enable/disable radio stations
- Unlock *some* of the early game gourds and modify where they have been placed
- Add/remove *some* items from the "Lost & Found" pedestal in the starting area
